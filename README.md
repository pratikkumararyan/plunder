# Plunder
A side-scroller, simple game thats based on the theme 'Treasure'. Here, you have to reach the flag at the top of the map before the water reaches you.
The player is spawned at the very bottom with simple introductory texts and slowly finds their way to the top through self-reinforcment

# How to play
W for JUMP
A for LEFT
D for RIGHT
SPACE FOR JUMP 
LEFT CLICK to throw coins

coins can only be thrown when you have coins.

# Features 
The game features a map made using opensourced assets from various vendors. Featuring two enemies: Star and Crab! resembling the oceon! 
get it? cuz the water is rising? ummm.. Okay, the enemies walk between two set points and they have 2 ranges: Inner range, Outer range. The enemy
only agros when the player walks into the inner range, that will cause the enemy to start following the player- abandoing its previous set points  for patroling.
the player can escape its agro by leaving the OUTER range, which is significantly larger than the inner range, else, if the player remains in the inner range
then, inside that inner range: if the user is a set amount of distance far away, the enemy will attack- dealing a set amount of damage but not killing the player.

The game features spikes, A LOT throughout the entire map and these are most dangerous!
